CarregarXML() Dim xmlDoc As Object Dim chNFeNode As Object Dim numNF As Object Dim ieEmit As Object Dim cnpjEmit As Object Dim ieTransp As Object Dim cnpjTransp As Object Dim placaVeic As Object Dim vlrUnit As Object Dim vlrXMLNF Dim pesoLiquido As Object Dim filePath As String filePath = Application.GetOpenFilename("Arquivos XML (*.xml), *.xml", , "Selecione o XML da NF-e") If filePath = "Falso" Then Exit Sub Set xmlDoc = CreateObject("MSXML2.DOMDocument.6.0") xmlDoc.async = False xmlDoc.Load filePath If xmlDoc.ParseError.ErrorCode <> 0 Then MsgBox "Erro ao carregar XML: " & xmlDoc.ParseError.Reason Exit Sub End If xmlDoc.SetProperty "SelectionNamespaces", "xmlns:nfe='http://www.portalfiscal.inf.br/nfe'" ' Atribuir ao objeto Set chNFeNode = xmlDoc.SelectSingleNode("//nfe:protNFe/nfe:infProt/nfe:chNFe") Set numNF = xmlDoc.SelectSingleNode("//nfe:infNFe/nfe:ide/nfe:nNF") Set ieEmit = xmlDoc.SelectSingleNode("//nfe:infNFe/nfe:emit/nfe:IE") Set cnpjEmit = xmlDoc.SelectSingleNode("//nfe:infNFe/nfe:emit/nfe:CNPJ") Set ieTransp = xmlDoc.SelectSingleNode("//nfe:transp/nfe:transporta/nfe:IE") Set cnpjTransp = xmlDoc.SelectSingleNode("//nfe:transp/nfe:transporta/nfe:CNPJ") Set placaVeic = xmlDoc.SelectSingleNode("//nfe:transp/nfe:veicTransp/nfe:placa") Set pesoLiquido = xmlDoc.SelectSingleNode("//nfe:transp/nfe:vol/nfe:pesoL") Set vlrUnit = xmlDoc.SelectSingleNode("//nfe:infNFe/nfe:det/nfe:prod/nfe:vUnCom") Set vlrXMLNF = xmlDoc.SelectSingleNode("//nfe:total/nfe:ICMSTot/nfe:vNF") ' Inserir nas cï¿½lulas If Not chNFeNode Is Nothing Then Range("D6").Value = chNFeNode.Text Else Range("D6").Value = "Não encontrado" End If If Not numNF Is Nothing Then Range("D21").Value = numNF.Text Else Range("D21").Value = "Não encontrado" End If If Not ieEmit Is Nothing Then Range("D18").Value = ieEmit.Text Else Range("D18").Value = "Não encontrado" End If If Not cnpjEmit Is Nothing Then Range("D19").Value = cnpjEmit.Text Else Range("D19").Value = "Não encontrado" End If If Not cnpjTransp Is Nothing Then Range("D16").Value = cnpjTransp.Text Else Range("D16").Value = "Não encontrado" End If If Not placaVeic Is Nothing Then Range("D13").Value = placaVeic.Text Else Range("D13").Value = "" End If If Not vlrXMLNF Is Nothing Then Range("K5").Value = vlrXMLNF.Text Else Range("K5").Value = "NÃO ENCONTRADO" MsgBox "Valor da NF não encontrado no XML.", vbCritical, "Erro de validação" End If ' Peso If Not pesoLiquido Is Nothing Then Dim pesoTexto As String pesoTexto = Replace(pesoLiquido.Text, ".", ",") If IsNumeric(pesoTexto) Then Range("D22").Value = CDbl(pesoTexto) Else Range("D22").Value = "" End If Else Range("22").Value = "" End If ' Inserir data de hoje Range("D17").Value = Format(Now, "dd.mm.yyyy") ' Valor unitï¿½rio do produto If Not vlrUnit Is Nothing Then Dim valorUnitTexto As String valorUnitTexto = Replace(vlrUnit.Text, ".", ",") If IsNumeric(valorUnitTexto) Then Range("D25").Value = CDbl(valorUnitTexto) Else Range("D25").Value = "Valor inválido" End If Else Range("D25").Value = "Não encontrado" End If ' Buscar informaï¿½ï¿½es adicionais da nota Dim infAdicNode As Object Set infAdicNode = xmlDoc.SelectSingleNode("//nfe:infNFe/nfe:infAdic/nfe:infCpl") If Not infAdicNode Is Nothing Then Range("B39").Value = infAdicNode.Text Else Range("B39").Value = "Não encontrado" End If End Sub
